
# 💈 Barbearia

Aplicação web para uma barbearia, desenvolvida em React e hospedada na Vercel.

## ✨ Funcionalidades

- Visualização de serviços e preços
- Agendamento de horários
- Galeria de trabalhos realizados
- Informações de contato e localização
- Design responsivo (mobile e desktop)

## 🚀 Tecnologias

- [React](https://react.dev/)
- [Vercel](https://vercel.com/) — deploy e hospedagem
- CSS / Styled Components *(ajuste conforme o projeto)*

## 📦 Instalação

Clone o repositório e instale as dependências:

```bash
git clone https://github.com/seu-usuario/barbearia.git
cd barbearia
npm install
```

## 🖥️ Rodando localmente

```bash
npm start
```

O projeto ficará disponível em `http://localhost:3000`.

## 🏗️ Build de produção

```bash
npm run build
```

## ☁️ Deploy

O projeto é publicado automaticamente na [Vercel](https://vercel.com/) a cada push na branch principal.

Para fazer o deploy manualmente:

```bash
vercel --prod
```
